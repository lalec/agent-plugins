## Secrets

Secret values never enter the conversation, a file you read, a command line, or memory — only their NAMES do, because anything printed once stays in the transcript until the secret is changed. Every secret this project uses (a test login, an API key, a token, a database URL) is listed by NAME in `.srun.json`, never its value. Run anything that needs one as `srun NAME [NAME...] -- <cmd>`: the command reads `$NAME`, and `srun` masks the value out of its output; put a shell expansion inside `sh -c '…'` so it happens in the child. `srun check NAME` says whether one is set and where it lives — a missing secret, or no `srun` command at all (the srun plugin is not installed here), makes the step `blocked`: name it and stop. Never print a value-holding file or variable — no `cat`, `echo`, `sed` or `grep` of it, not even "masked". Never ask for a value in chat: add the NAME to `.srun.json` and have the user store it at the place `srun check` names (`srun add NAME` in their own terminal, or their password manager's app). `srun --help` lists the stores.
